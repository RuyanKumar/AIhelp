# SkillPath – Eisenhower Matrix

## DO – My MVP
- Let students choose what they want to learn.
- Let students select their experience level.
- Create a learning plan based on their choices.
- Let students mark completed topics.
- Save their learning progress.

## SCHEDULE – For V2.0+
- Add more subjects to learn.
- Add quizzes to test students.
- Show progress using charts.
- Let students set weekly goals.

## DELEGATE – Use a Library
- Use Java Scanner to get user input.
- Use ArrayList to store learning topics.
- Use Java file handling to save progress.

## DELETE – Cut It
- Do not add a social media feature.
- Do not add live video lessons.
- Do not add a payment system.
- Do not build a complicated AI system.
