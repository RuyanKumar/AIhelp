# AIhelp

## Project Goal
AIhelp is a Java program that helps students learn skills like Python, Data Science, and AI. It gives students a learning plan based on what they want to learn and their current experience level.

## MVP Scope
- Students can choose a skill they want to learn.
- Students can select their experience level.
- The program gives them a step by step learning plan.
- Students can mark topics they have completed.
- The program saves their learning progress.

## Future Plans
- Add more skills and subjects.
- Add quizzes to test students.
- Show learning progress using charts.
- Allow students to set weekly learning goals.

## Tech Stack
- **Language:** Java
- **Libraries:** Scanner, ArrayList, and Java File Handling.
- **Data Storage:** A simple text file to save learning progress.
- **Development Tools:** IntelliJ IDEA and GitHub.
- **External Data Sources:** No external APIs are needed. Learning topics will be stored directly in the program.
